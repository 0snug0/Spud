# SPD-006 — Ledger database spike: what replaces markdown-v0

## Brief
Eric asked for the ledger database spike, the first real ticket after bootstrap. The brief is Appendix A of `docs/superpowers/specs/2026-09-12-spud-design.md`: answer eight questions with evidence (store, topology, schema, concurrency, migration, glue language, enforcement, fleet view and reports) and write `docs/spikes/2026-09-12-ledger-database.md` with the ten sections named there. The spike decides what replaces `markdown-v0`; it does not implement it. No code files; DDL in a code block is spec, not code. Eric's stated need from 2026-09-12 (question 8) is in scope: click a ticket and see the lead, every spudagent under it with persona, model, and status, and a summary of what they worked on and built.

Done when: the spike file exists with all ten sections in order, each of the eight questions has an evidenced answer and one recommendation rather than a menu, measurements come from this machine and say so, sources are cited, the researcher's proposals and open questions for Eric are recorded, the outcome is recorded here, and the work is committed.

## Size, persona and model decision
One researcher, who may build a team of up to two, because the brief says so and the work has separable evidence-gathering parts (prior-art survey, native-facts lookup, machine measurements) around one indivisible synthesis.

- Lead: [[SPUD-006/Vitelotte|Vitelotte]] (01, researcher, **fable**). Default tier for the persona, no override. Eric specified researcher on fable, and the spike is the decision every later ticket builds on: data model, concurrency, and enforcement are the "expensive if wrong" category.
- Optional children, Vitelotte's call: a scout on haiku for the Minilla prior-art survey or the latency and concurrency measurements, and/or a `claude-code-guide` contractor (recorded with `persona: contractor`, `agent_type: claude-code-guide`, explicit model) for native facts about hook payloads and what the Agent tool returns. Depth remaining below Vitelotte is 1, so any child gets "no sub-agents".

Concurrency: at most 1 + 2 = 3 of 9.
