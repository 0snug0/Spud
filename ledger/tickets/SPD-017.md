# SPD-017 — CLI ergonomics: accept the member handle wherever a ref is taken; member list

## Brief
In the [[SPD-008]] headless probes the main agent typed `spud member list --json` (no such command; it wanted a ticket's team, which is `spud card`) and `spud member finish "SPUD-001/Kestrel (01, scout)"` (the handle form, not a ref) before finding the right forms; each miss cost a turn. Make `bin/spud` accept the handle `SPUD-nnn/Name (lineage, persona)` wherever a member ref is taken, and add `member list [--ticket SPD-nnn]` as an alias of `card`'s team listing, with `--json`. Evidence: Desiree's proposal 3 and the probe summaries quoted in her Result. [[SPD-009]] teaches the canonical forms; this ticket makes the CLI forgiving of the obvious variants.

Done when: red-first tests for both forms, the suite is green, `--help` lists the alias.

## Size, persona and model decision
One engineer on sonnet (mechanical parsing changes, guarded by the existing suite).
