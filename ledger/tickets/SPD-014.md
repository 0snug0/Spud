# SPD-014 — Cross-repository projects: BadTakes and other repos Spud works in

## Brief
The spike's Topology ([[SPD-006]]) supports many projects in one database but v1 does not exercise it. This ticket adds `spud project add`, installs the hooks and `SPUD_HOME` for sessions started inside another repository, and writes the `~/.config/spud/home` pointer for sessions where neither the env var nor the git common dir applies.

Waits on Eric's answers to open questions 2 (ticket numbering across projects) and 8 (whether v1 should cover other repositories).

Done when: a ticket for BadTakes runs from a session started in that repository and lands in the one ledger.

## Size, persona and model decision
An architect on fable to settle the project model, then an engineer on opus.
